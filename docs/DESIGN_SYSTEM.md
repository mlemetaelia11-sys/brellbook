# BrellBook Design System

The attached design references are included in `docs/design-reference/` and were used as the visual direction for this implementation.

## Parent brand
Brell — Technology that moves businesses forward.

## Product
BrellBook — Book it. Don't miss it.

## Palette
- Purple `#6C2BFF`
- Deep Indigo `#1B1B3A`
- Coral `#FF5A4E`
- Aqua `#21D0C3`
- Yellow `#FFC838`
- Background `#F7F8FC`

## UI
Desktop uses a dark indigo sidebar and light workspace. Mobile uses a bottom navigation bar. Cards are rounded, whitespace is generous, shadows are subtle, and the main action uses Brell Purple.
